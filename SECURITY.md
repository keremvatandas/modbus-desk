# Security Policy

## Supported Versions

The latest released version is the supported version.

## Reporting a Vulnerability

Please report security issues privately by email:

```text
keremvatandas@gmail.com
```

Include:

- A short description of the issue.
- Steps to reproduce it.
- Expected impact.
- Relevant logs, screenshots, or proof-of-concept details if available.

Please do not open a public issue for suspected security vulnerabilities until there has been time to review and fix the report.

## Industrial Safety

ModbusDesk can write to industrial devices. Treat every write operation as potentially device-impacting. Test against a simulator or lab device before using it against production equipment.
